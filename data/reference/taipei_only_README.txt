Taipei-only YouBike trips
Both endpoints must uniquely match Taipei City in the official 2026-11-16 station snapshot.
Outside-city, cross-city same-name ambiguity and unmatched names are excluded.
Historical station identities cannot be proven from names alone; the filter is conservative.
CSV files use UTF-8 BOM. Parts contain at most 500,000 retained rows and preserve their relative source order.
The raw version has 8 original fields. The coordinates version adds rent_latitude, rent_longitude, return_latitude, return_longitude.
No original Parquet was changed. All CSV values and coordinates were checked before packaging.
Use MANIFEST.json for row counts and SHA-256 values. Do not concatenate both versions as distinct trips.
